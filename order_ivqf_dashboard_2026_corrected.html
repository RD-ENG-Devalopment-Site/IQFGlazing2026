ระบบ Glazing และความเหมาะสม

เลือกหัวข้อเพื่อดูรายละเอียด
Dip Glazing: ระบบจุ่มจุ่มสินค้า IQF ในน้ำเย็น แล้วสะเด็ดให้เป็นฟิล์มน้ำแข็ง

หลักการ

น้ำสัมผัสผิวสินค้าโดยรอบ เวลาและอุณหภูมิน้ำกำหนดความหนาของ glaze

ควบคุม

ใช้น้ำเย็นไหลต่อเนื่อง หลีกเลี่ยงถังน้ำนิ่งและการกักน้ำ

ความเหมาะสม

ไม่แนะนำเป็นมาตรฐานสำหรับ BL, BB, FL เพราะเสี่ยง % glaze แกว่ง

Spray Glazing: ระบบพ่นน้ำพ่นน้ำเย็นเป็นละอองหรือม่านน้ำโดยไม่จุ่มสินค้า

หลักการ

คุม glaze ด้วยเวลาพ่น แรงดัน อัตราการไหล และอุณหภูมิสินค้า

ควบคุม

พ่นบน–ล่าง ตรวจหัวพ่นอุดตัน และไม่ให้สินค้าซ้อนกัน

ความเหมาะสม

เหมาะที่สุดกับ BL, BB และ FL

Belt Glazer: เครื่องพ่นบนสายพานSpray แบบต่อเนื่องที่คุมเวลาพ่นด้วยความเร็วสายพาน

หลักการ

สินค้าเคลื่อนผ่านหัวพ่นบน–ล่างบนสายพานตะแกรง

ควบคุม

Loading, ความเร็วสายพาน และ coverage ด้านล่าง

ความเหมาะสม

เหมาะมากกับ BL, BB และ FL เป็นระบบมาตรฐาน

Vibrating Glazer: ระบบพ่นพร้อมการสั่นช่วยแยกชิ้นและสะเด็ดน้ำส่วนเกิน

หลักการ

การสั่นเปิดผิวสินค้าให้รับน้ำทั่ว ไม่ได้มีเป้าหมายเพื่อเพิ่มน้ำ

ควบคุม

คุมแรงและความถี่ ไม่ให้เนื้อแตกหรือ glaze หลุด

ความเหมาะสม

เหมาะกับ BL 25–30 g เมื่อใช้แรงสั่นเบา

Double Dip Glazer: ระบบจุ่มสองครั้งจุ่มซ้ำหลังชั้นแรกแข็งตัว เพื่อเพิ่มการปกป้อง

หลักการ

จุ่ม → เซตตัว → จุ่มซ้ำ → สะเด็ดน้ำ

ควบคุม

ระวัง overglaze และความร้อนที่สินค้าได้รับ

ความเหมาะสม

ไม่ใช้เป็นมาตรฐาน BL, BB, FL เว้นแต่สเปกลูกค้ากำหนด

คู่มือควบคุมและแก้ปัญหาแต่ละระบบ

ระบบลำดับการทำงานตัวแปรสำคัญที่ต้องคุมความผิดปกติ / แนวแก้คำแนะนำกับ BL, BB, FL

SprayIQF → จัดเรียงชิ้น → พ่นบน–ล่าง → สะเด็ด → บรรจุแรงดัน, อัตราการไหล, มุมหัวพ่น, เวลาในโซนพ่น, อุณหภูมิสินค้าและน้ำจุดไม่เคลือบ: ตรวจหัวพ่นอุดตัน/ชิ้นซ้อน; Overglaze: ลดเวลา/ปริมาณน้ำหลักการที่แนะนำสำหรับ BL, BB, FL ทุกขนาด
BeltIQF → สายพานตะแกรง → พ่นบน–ล่าง → สะเด็ด → เซตตัวความเร็วสายพาน, loading ต่อพื้นที่, สภาพตะแกรง, coverage ใต้ชิ้น% ไม่คงที่: ตรวจความเร็วและ loading; ด้านล่างโผล่: ปรับหัวพ่นล่างระบบมาตรฐาน: BL 8%, BB 5%, FL 6% เป็นจุดเริ่ม Trial
VibratingIQF → สั่นเบาเพื่อแยกชิ้น → พ่น → สั่นสะเด็ด → เซตตัวความถี่, แรงสั่น, มุมราง, ระยะเวลาสั่น และจำนวนชิ้นต่อรางชิ้นแตก/glaze หลุด: ลดแรงสั่น; ชิ้นติดกัน: เพิ่มการกระจายชิ้นก่อนพ่นเหมาะกับ BL 25–30 g; BB และ FL ใช้เฉพาะแรงต่ำเมื่อจำเป็น
Double DipIQF → จุ่มรอบ 1 → สะเด็ด/เซตตัว → จุ่มรอบ 2 → เซตตัวเวลาจุ่มแต่ละรอบ, ความสมบูรณ์ของชั้นแรก, อุณหภูมิสินค้า/น้ำ, น้ำหนักหลัง deglazeOverglaze/สินค้าอุ่น: ลดเวลาจุ่มและต้องให้ชั้นแรกแข็งตัวก่อนจุ่มซ้ำไม่แนะนำเป็นมาตรฐานของ BL, BB, FL ใช้เมื่อสเปกลูกค้าหรือ shelf-life test กำหนด
