LINE BALANCING SIMULATOR

คู่มือการใช้งาน Web App

สำหรับตั้งค่า Line, ตรวจ Bottleneck, ปรับ Manpower/Productivity, เก็บหลักฐาน และตัดสินใจนำ Recommendation ไปใช้จริงอย่างมีเงื่อนไข

ภาษาไทยอ้างอิง Simulator schema v3อัปเดต 18 กันยายน 2026

เริ่มต้นอย่างรวดเร็ว

ใช้เส้นทางนี้เมื่อเพิ่งเริ่มวิเคราะห์ผลิตภัณฑ์หรือ Line ใหม่

  1. กำหนด Setupระบุ Product name, Pack weight, Feed method, Baseline manpower, Target และ Safety Buffer
  2. ตรวจ Capacity ของแต่ละ Stationเปิด Station ที่ต้องการ แล้วปรับ Manpower หรือ Productivity / Team
  3. อ่าน Live decision snapshotดู Bottleneck, Output, ความเปลี่ยนแปลงจาก Scenario A และคำแนะนำถัดไป
  4. บันทึก Evidenceกรอกแหล่งข้อมูล, วันที่วัด, จำนวนตัวอย่าง และผู้รับผิดชอบใน Station dropdown
  5. ทำ Trial readinessบันทึกผล Trial, วันที่, ผู้อนุมัติ และตรวจ WIP, Delay, Break, Ergonomics
  6. บันทึก Scenarioเก็บ Current เป็น A และข้อเสนอ/ผลทดลองเป็น B แล้ว Export JSON หากต้องการส่งต่อ

1. Setup: ข้อมูลพื้นฐานของ Line

Target / Machine Capacityเป้าหมายกำลังผลิตของทั้ง Line หน่วย kg/hr ต้องไม่น้อยกว่า 100
Safety Bufferส่วนเพิ่มเหนือ Target เพื่อให้ Auto Balance คำนวณ Safe Target เช่น Target 700 และ Buffer 10% จะได้ 770 kg/hr
ช่องข้อมูลใช้ทำอะไรข้อควรระวัง
Pack weightแปลง kg/hr เป็น ถุง/hrต้องมากกว่า 0
Feed methodกำหนด Feed Station เป็น kg/Team/hr หรือ ถาด/Team/hrถ้าใช้ถาด ต้องระบุน้ำหนักเฉลี่ยต่อถาด
Baseline manpowerใช้เป็นค่าตั้งต้นสำหรับการเปรียบเทียบต้องเป็นจำนวนเต็มตั้งแต่ 1 คน
เมื่อข้อมูลไม่ถูกต้องระบบจะแสดงกรอบแดงและไม่ให้ Apply Recommendation หรือ Save Scenario โดยผลคำนวณจะยึดค่าล่าสุดที่ผ่าน Validation

โหมด Auto Balance

Lean - Target onlyคำนวณให้ถึง Target เหมาะสำหรับการวิเคราะห์เชิงทฤษฎี
Safe - + Bufferคำนวณให้ถึง Safe Target เหมาะเป็นค่าเริ่มต้นสำหรับการทดลองหน้างาน
Team size สำคัญCapacity จะเกิดเมื่อจำนวนคนครบ Team เท่านั้น คนที่เหลือไม่ครบ Team จะถูกแจ้งเตือนและไม่เพิ่ม Capacity

3. Evidence & data basis

อยู่ใน Dropdown ของแต่ละ Station เพื่อบันทึกที่มาใกล้กับตัวเลขที่กำลังปรับ

Data typeสิ่งที่ต้องทำผลต่อสถานะ
Actual / Trialเลือก Basis/source, Measured date, Sample count และ Owner ให้ครบEvidence needed จนกว่าจะครบ
Assumption / Targetใช้เพื่อวางแผนหรือจำลองก่อนมีข้อมูลวัดจริงPlanning only
Support Stationหากปิด Use in capacity จะไม่นำไปหา BottleneckOptional สำหรับ Evidence

Basis/source เลือกได้จาก Time study, Production report, Trial record, Standard work หรือ Other documented source

4. อ่านสถานะตัดสินใจ

คำว่า Ready จะปรากฏเมื่อทุกเงื่อนไขผ่าน ไม่ใช่เพียง Capacity ถึงเป้า

สถานะความหมายและสิ่งที่ต้องทำ
Check inputsแก้ข้อมูลที่มีกรอบแดงก่อน ระบบจะคงผลจากค่าล่าสุดที่ถูกต้องไว้ชั่วคราว
Capacity not readyยังมี Station ต่ำกว่า Target ต้องแก้ Bottleneck ก่อน
Buffer not readyถึง Target แล้วแต่ยังไม่ถึง Safe Target; เพิ่ม Buffer หรือใช้ Lean mode พร้อมบันทึกเหตุผล
Planning only / Evidence needed / Trial requiredCapacity อาจผ่านแล้ว แต่ยังไม่พร้อมนำไปใช้จริง
ReadyInput ถูกต้อง, ทุก Capacity Station ผ่าน Safe Target, Evidence ครบ และ Trial checks ผ่าน

5. Trial readiness และการนำไปใช้

  • เลือก Trial status เป็น Passed
  • ระบุ Tested date และ Approved by
  • ทำเครื่องหมายว่าได้ตรวจ WIP, Delays, Breaks และ Ergonomics แล้ว
  • ทบทวน Live decision snapshot ก่อนเปลี่ยนกำลังคนถาวร
แนวปฏิบัติที่แนะนำเริ่มจาก Safe mode, ทดลองในช่วงเวลาที่กำหนด, เก็บผลจริง แล้วจึงลดคนถาวรเมื่อสถานะ Ready

6. Scenario, Autosave และการแลกเปลี่ยนข้อมูล

คำสั่งใช้เมื่อ
Save Current → Aบันทึก Baseline หรือสภาพก่อนปรับ
Save Current → Bบันทึกข้อเสนอที่ปรับแล้วหรือผลหลัง Trial
Load A / Load Bเรียก Scenario กลับมา โดยระบบถามยืนยันและสามารถ Undo ได้
Undoย้อนกลับการ Apply, Reset, Load, Remove หรือการบันทึกทับ Scenario ล่าสุด
Export JSONส่งข้อมูลไปเก็บสำรองหรือส่งให้ทีมอื่น
Import JSONนำข้อมูลกลับเข้า App; ระบบตรวจ Schema และ Station ID ก่อน Import
Autosaveข้อมูลจะบันทึกอัตโนมัติใน Browser และบันทึกทันทีเมื่อซ่อนหรือออกจากหน้า ควร Export JSON ก่อนเปลี่ยนเครื่องหรือส่งต่อให้ผู้อื่น

คำถามที่พบบ่อย

ทำไม Output ไม่ขยับหลังกรอกข้อมูล?

ตรวจว่าค่าเป็นตัวเลขที่ผ่าน Validation, Station เปิด Use in capacity และจำนวนคนครบ Team หรือไม่

ทำไม Apply Recommendation ใช้ไม่ได้?

มีข้อมูลที่ไม่ผ่าน Validation อยู่ ระบบจะเปิดใช้งานปุ่มเมื่อแก้ข้อมูลครบแล้ว

ทำไมยังไม่ขึ้น Ready ทั้งที่ Capacity ผ่าน?

ตรวจ Evidence ใน Station ที่เป็น Actual/Trial และตรวจ Trial status, วันที่, ผู้อนุมัติ และ checklist ทั้ง 4 ข้อ

Import JSON ไม่ผ่าน?

ตรวจว่าไฟล์เป็น JSON จาก Simulator, มี Station ID ไม่ซ้ำ และไม่ได้สร้างจาก schema ที่ใหม่กว่าระบบปัจจุบัน
