รอบนี้จุดเข้าเครื่องอยู่ 4–8°C และไม่มีจุดใดต่ำกว่า 4°C ควร Pre-chill และยืนยันค่า warmest core ก่อนเริ่ม เพื่อไม่ให้โหลดความร้อนเริ่มต้นกลบผลของ Condition เครื่อง

ทดลองเวลาเดินสายพาน 3 ระดับที่ −95°C

ใช้ 7:20 เป็น Baseline แล้วทดสอบ 9:30 และ 11:30 นาที โดยคงน้ำหนักต่อพื้นที่ ความหนาชั้นสินค้า และระยะห่างให้เท่ากัน หากชิ้นสินค้าตกเมื่อเพิ่มความเร็ว ให้คง/ลดความเร็วและแก้ด้วย guide หรือการจัดเรียง ไม่ควรเพิ่มความเร็วจนเวลาพักสั้นลง

วัด Core ด้วยหัววัดที่เหมาะกับชิ้นสินค้า

วางหัววัดที่แกนกลางชิ้นจริงและระบุตำแหน่งซ้าย–กลาง–ขวาของสายพานอย่างน้อยตำแหน่งละ 3 จุด แยก Logger อุณหภูมิอากาศออกจากหัววัด Core เพราะ iButton อาจใหญ่เกินไปสำหรับ BLK 20–30 g

กำหนดเกณฑ์ผ่านที่จุดออกและหลัง Glazing

เลือก Condition ที่ warmest core ของทุกจุด ≤ −18.5°C และ coldest core ไม่ต่ำกว่า −22.0°C ทั้งก่อน Glazing และที่ 0, 15, 30 นาที ทำซ้ำอย่างน้อย 3 รอบก่อนล็อกมาตรฐาน

ติดตามคลังต่ออย่างน้อย 36–40 ชั่วโมง

รอบนี้ 31 ชั่วโมงยังไม่พอ ให้บันทึกต่อจน warmest core ≤ −18.5°C ต่อเนื่องอย่างน้อย 3 ค่า พร้อม Logger อุณหภูมิอากาศคลังและตำแหน่งพาเลต เพื่อแยกผลของ airflow และการซ้อนสินค้า

ล็อกนิยามเวลา 0, 15, 30 นาที

เริ่มจับเวลา 0 นาทีทันทีหลังยกสินค้าพ้นน้ำ Glazing และกำหนดเวลาสะเด็ดน้ำ/บรรจุคงที่ ไม่ใช้เวลาหลังเริ่มบรรจุแทน เพื่อให้เทียบรอบทดลองได้ตรงกัน
